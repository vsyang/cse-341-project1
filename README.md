# cse-341-project1

A 2 week project that will store Contacts such as friends or work colleagues.

In week one, I will need to: 
    1. Set up the project and database
    2. Import data into the database
    3. Complete the GET API routes - get and get all
    4. Deploy the app to Render

In week two, the completion of the project includes:
    1. Database storage that stores first name, last name, email, favorite color, and birthday
    2. Node project successfully connects to MongoDB
    3. API routes perform GET, POST, PUT, and DELETE requests that are fully functional.
    4. API Documentation using Swagger - professional, comprehensive, relevant, and accurate
    5. API is published to Render and can be called from external sources.
